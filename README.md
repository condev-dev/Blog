# 📝 Bibag

**Bibig** – A modern, responsive, and interactive blogging platform prototype.  
Crafted with **HTML, CSS, JavaScript, Bootstrap, and FontAwesome**, built for **dynamic UX, design flexibility, and fully responsive layouts**.

> 🚀 **Portfolio-Level Project** – Showcasing Senior Front-End engineering skills, advanced interactivity, and design polish.

## ✨ Key Highlights

> Designed and engineered with **Senior Front-End principles**, focusing on interactivity and user experience:

- 🏠 **Homepage** – Featured posts, interactive content sliders, clean responsive layout  
- 📄 **Pages** – About Us, Categories, Single Post, 404 Error (fully implemented and responsive)  
- 🎨 **Theme Switcher** – Light/Dark mode toggle for a personalized user experience  
- ⚡ **Interactive Components** – Sliders, hover effects, buttons, FontAwesome integration  
- 📱 **Fully Responsive** – Optimized for all screen sizes and devices
